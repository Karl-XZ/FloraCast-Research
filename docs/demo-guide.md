# 四项核心功能使用流程

在线入口：[独立部署](https://openl.work/FloraCast/) / [ModelScope](https://modelscope.cn/studios/Karlzhy/FLORACAST)。

演示视频：[FloraCast 气候与植被分析平台](https://www.bilibili.com/video/BV1UyJt6yETe/)。

## 1. 地图、遥感图层和分屏对比

1. 在地图中选择一个地点，记录坐标。
2. 打开图层面板，选择卫星影像、植被相关图层或气象图层。
3. 调整日期和透明度，确认实际返回的图层与日期。
4. 开启分屏，为两侧分别设置日期或图层，拖动分界线对比。

可以观察同一区域在不同时间的地表变化，也可以对照影像与植被空间分布。记录图层产品、日期、坐标和视图范围，便于之后重复查询。

## 2. 植物照片与种类识别

1. 打开植物照片功能，设置地点、半径与起止日期。
2. 加载 iNaturalist 观测，打开地图上的记录。
3. 查看照片、物种标注和观测日期，通过原始链接查看完整记录。
4. 选择照片识别操作，或在识别面板上传本地图片；需要时填写器官和地区提示。
5. 查看候选物种、分数和解释；将结果与原始照片、观测标注和形态特征对照。

这一流程把遥感中看到的植被变化联系到具体植物。照片数量受当地观察者、日期、上传情况和许可影响。调查记录应保留观测 ID、图片作者与原始链接。

## 3. 基于地点数据的 AI 助手

1. 确认地图所选坐标。
2. 加载需要的气象、植被指数及物候信息。
3. 打开 AI 助手，输入问题，例如：

   > 根据近期气温、降雨和植被指数，这里的植被状况如何？近期天气可能怎样影响开花？

4. 核对回答中使用的数据来源、日期与范围，再根据需要继续追问。

助手整理天气、植被和花期估计之间的联系，为进一步调查提供线索。天气与植被指数的变化可用于提出假设；解释具体生态原因时，还需要结合物种、地面观测与研究设计。

## 4. 历史气象搜索与信息对照

1. 打开自然语言历史天气搜索，输入地点、年份、月份和窗口长度。例如：

   > 查找青岛2020至2024年四五月持续两周的少雨时段。

2. 发起检索后，先检查解析出的坐标、年份、月份、窗口长度与条件权重。
3. 查看候选窗口、排序分数、降水量和连续少雨日数，以及逐日气象曲线。
4. 选择一个候选事件，查看对应地点和事件日期的影像；将照片查询范围调整到该事件，加载同期地面记录。
5. 打开植被分析，核对产品实际合成日期，再与天气过程进行比较。

这一流程能够快速缩小需要人工查阅的历史范围。研究者可比较多个天气相近的时期，考察当时植被与植物观测的共同点和差异。

### 时间范围检查

历史事件、卫星合成周期、照片日期与 AI 上下文具有不同时间粒度。当前代码中的事件选择会设置共享事件日期，并更新部分日期控件与地图图层；各面板是否重新请求数据，应检查实际结果：

| 信息 | 使用时记录什么 |
|---|---|
| 历史事件 | 完整起止日期及逐日气象序列 |
| 遥感影像 | 所选图层日期与实际可获得影像 |
| NDVI / EVI | 数据返回的合成日期；当前面板存在“最新合成”查询 |
| 植物照片 | 观测日期、过滤区间与观测 ID |
| AI 上下文 | 回答所用气象区间、植被合成日期与物候年份 |

比较多个时段时，保留这些字段，避免将不同日期的结果混入同一次比较。

## 其他功能

- **积温与花期估计**：根据逐日温度和植物参数计算积温，查看阈值达到时间。
- **月度物种与传粉昆虫记录**：按年、半径和分类单元查看观测分布，辅助安排调查。
- **斑块分析与时序预测**：查看区域植被统计和短期趋势估计；训练误差与独立预测误差分开记录。
- **可视化 GeoML**：在地图上查看所选环境特征的分类或聚类结果。
- **研究工作台**：保留独立任务、数据记录与报告入口，原有详细说明见 [技术文档](FloraCast_Deep_Research_Agent_Technical_Specification.md)。
